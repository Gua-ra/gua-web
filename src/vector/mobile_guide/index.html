Gua Web is optimized for desktop browsers

For the best experience, open Gua Web in a desktop browser.

On a mobile device?

Use a Gua beta app. The apps are not yet available in public app stores and are currently available to testers signed up for the Gua beta program.

Continue on web anyway

You can still use Gua Web in this browser, although some screens work best on desktop.
